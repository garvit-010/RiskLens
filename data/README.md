# RiskLens – Data Directory

## Sources

| Dataset | Source | Version / Date | License | Location |
|---|---|---|---|---|
| Financial News Headlines | Kaggle (human download) | As downloaded | Public | `raw_samples/news.csv` |
| Stock Tweets | Kaggle (human download) | As downloaded | Public | `raw_samples/tweets.csv` |
| Financial PhraseBank | Kaggle / Malo et al. 2014 | As downloaded | CC BY-NC-SA 3.0 | `raw_samples/phrasebank.csv` |
| SVB Replay | **Curated synthetic** – events based on publicly available news | 2023-03 | N/A | `raw_samples/replay_svb.jsonl` |
| Synthetic Portfolio | **Fully synthetic** – fixed seed 42 | Generated by `portfolio.py` | N/A | `portfolio/portfolio.csv` |
| Scenarios | **Documented assumptions** | Defined in `scenarios.py` | N/A | `scenarios/scenarios.yaml` |
| Labeled Events | **Draft labels** – to be reviewed by human | Human-corrected | N/A | `labeled_eval/labels.csv` |
| Price Cache | yfinance (public market data) | Cached locally | Public | `raw_samples/prices/` |

## Assumptions

1. **Portfolio data is entirely synthetic.** Random seed 42. Distribution shapes are plausible but not calibrated to any real institution.
2. **SVB replay events** are inspired by public news from March 2023 but the exact text is original. Do not present as real quotes.
3. **Scenario shock magnitudes** are documented assumptions, not empirically calibrated. See `docs/ASSUMPTIONS.md`.
4. **All Kaggle data** is used under the respective dataset licenses for non-commercial academic purposes.

## No Proprietary Data

No S&P Global, Crisil, or any client data is used anywhere in this repository.
All data is either synthetic, public-domain, or downloaded by the candidate from public sources.

## How to Download Kaggle Data

1. Create a Kaggle account at kaggle.com
2. Download the datasets and place them at the paths shown in the table above
3. Run `python run.py --precompute` to process them through the engine
